# 户籍与市政经营

## 当前版本

- 城镇建设提供道路、石城墙、城门和铁匠铺。道路与城墙可连续铺设。接入同一路网的完工住宅，每栋只计一次。沿道路或城门走 14 格能抵达 20 座住宅，并有紧邻道路的三乘三块空地，街区就能在日结形成集市。房屋的统计不跨断路，已有集市 28 格内避免重复开市。
- 居民以固定户号登记。资产估值由现金、田亩、渔船和私人建筑组成。地块和船数决定潜在产量，成年人口与服役、官府岗位共同决定当天可上工人数。缺人时，地契或船主可用自己的现金支付工钱；同一份工时每天只分配一次。
- 本地家庭先吃自产，再用现金交易余粮；部分剩余产出外销。公仓只补私粮缺口，军粮仍按原军需规则从公仓扣除。标准田税为产出的 18%，捕鱼征收较低的渔税。牧场、采石和伐木保留官府经营。店铺标准营业税是营业额的 22%，所以同等收入下商税率高于田税，再按照税务官能力提高实收。
- 居民按可用现金、劳力、市场需求和临水条件买田、置船、开店。商号需有临街空地，周边商铺容量受集市数影响。资产、天候、收成、店铺客流和修缮均使用不同抽样通道。伪随机种子随档保存，读档后同一日的结算可重放。
- 旧领主农场移交为民田，渔场改为民用码头并分给产权户。建筑和工地的位置、进度都保留，原官府雇员释放，未完工部分由户主自行完成。
- 首版设一名税务官和一名带兵武将。成年、家资不少于 240 金及对应能力不低于 60 才能候选。文武不得同户兼任。武将须绑定驻主城的现役军团；军团离城后锁定人选，撤销军团解除职务。文才影响商税实收，武略提高所辖军团的出战值。已有战斗继续用开战时记录的数据。

## 科举与武举的后续规则

1. **资格。** 有成年成员即可报名；科举考察文才与执行经历，武举考察武略与军旅或训练经历。正式考试启用后，家产不计入考试分数，也不作为报名门槛。当期文武两科只能报一科。
2. **评分。** 科举建议按策论 45、财赋 35、律例 20 合计。武举按训练 35、统御 40、后勤 25 合计。每科的临场波动限制在正负 5 分，按考试期和户号保存结果。总分同分先比较该科主项，再比较相关经历，仍同分按固定报名序号排位。
3. **复核与回避。** 任职官员只能从合格名单提名。同户与直系关系必须回避，阅卷时先隐藏户籍和资产。提名需显示分数、资历和岗位匹配理由；跨过前列候选人必须留下理由，避免单靠官员偏好或财富取人。
4. **任用。** 由在职官员提出名单，领主任命。人员不足时允许领主从合格名单直接任命并登记原因。文官先在税务或仓储轮岗，武将先从驻城军团或训练岗位试任。考试分数和任职实绩分别记录。

数值为首版平衡参数。
