# 林矿资源与建设材料生产验收

## 本步目标与范围

用户选择加入森林和石矿资源点，对应建筑必须靠近对应资源。现在城镇建设可以通过伐木场和采石场持续补充木材石材；粮食、住房、粮仓和税收沿用前步规则。使用色块和“林/矿”字符作为临时标记，没有确定最终像素美术。

## 配置与位置

| 建筑 | ID | 占地 | 木/石/金币费用 | 工作量 | 岗位 | 每人每日 | 满员每日 |
|---|---|---|---|---|---|---|---|
| 基础伐木场 | b_lumber | 3×3 | 0/0/10 | 60 | 3 | 木材8 | 木材24 |
| 采石场 | b_quarry | 3×3 | 25/0/15 | 80 | 3 | 石材5 | 石材15 |

全部数值待平衡。两名施工工人每战略秒完成一份工作；一日120战略秒。基础伐木营地只消耗金币，避免存粮与木材耗尽后失去恢复建设材料的路径。金币仍可通过日结税收获得。采石场不消耗石材，可由伐木场生产的木材启动。

静态森林位于(0,11)、(0,12)、(0,13)，石矿位于(15,4)、(15,5)、(15,6)。示例合法锚点：伐木场(1,10)，采石场(12,4)。绿色林格、灰白矿格与蓝色水域区分。

建筑完整占地必须在地图内、空闲、位于非资源点的陆地。占地至少一格与对应资源格正交相邻；斜角不算，资源类型不能互代。普通建筑也不能新建在资源点上。预览、确认以及新增采集建筑读档使用同一地形规则。失败不扣费、不创建实例或命令回执。

## 生产、人口与日结

两个新建筑使用现有生产岗位池：总人口30 = 被抚养6 + 施工工人 + 所有食物和材料生产工人 + 空闲。工地不可分配，完工默认0人，需要玩家操作。两座满员合计6人，施工2人时空闲16；同时有农牧渔满员8人时空闲8。

保留food_credit，新增独立整数material_credit：

    每战略秒 material_credit += 在岗人数 × 每人每日材料
    每日日结 produced = floor(material_credit / 120)
    之后 material_credit %= 120

生产在施工推进之前累计，刚完工建筑从下一战略秒具备生产资格。暂停不积累，倍速只推进战略时间。调岗按实际工作量计产量，不会在日结前调人就获得整日收益；撤岗保留已经完成的工作。每栋建筑只产一种材料，伐木场和采石场不会产生粮食信用，原食物建筑也不产生材料信用。

日结按既有顺序计算粮食，再入库材料，最后加税并记录日期。木石安全上限10亿，stored=min(produced, 10亿-opening)，超过部分作为明确溢出记录；这不是材料仓库玩法。无维护扣料、工具、搬运工或生产半径效率。

## 存档与模块

战略快照v7新增每栋建筑material_credit和根字段last_material_ledger，非材料建筑为0。v1至v6读取时补0、不补发历史材料、不虚构历史材料账单；粮食信用、岗位、建筑位置和资源均保留。SQLite表结构仍v2，使用原事务与滚动备份。

新增字段示例：

```json
{
  "version": 7,
  "last_material_ledger": {
    "day": 3,
    "wood": {"opening": 95, "produced": 24, "stored": 24, "overflow": 0, "closing": 119},
    "stone": {"opening": 80, "produced": 15, "stored": 15, "overflow": 0, "closing": 95}
  }
}
```

此片段只说明新增字段，完整世界快照还包含前步已有的日期、库存、建筑、粮食账单等字段。建筑记录示例新增material_credit=1464，代表伐木场3人已工作61战略秒，对应12.2待入库木材；不足整数部分随存档保留。

material_ledger.gd负责材料收支计算、完整校验与JSON整数恢复。拒绝无效日期、缺字段、负数、小数和不守恒账单；world_state校验材料进度、岗位、建筑地形及迁移；world_prototype仅显示单位/预测/累计/日结摘要并发送分配请求。静态建筑.tres新增material_resource、material_per_worker_day和required_deposit，用途由此文档说明。

固定资源点属于静态地图。旧建筑即使覆盖新增资源点仍保留原位置与工作状态，不强制拆除或移动；新建规则收紧。当前不记录动态资源总量，后续接入枯竭、再生或随机区域时需正式地图版本与迁移，不能重新生成玩家城镇。

人工测试方法见开发测试指南步骤十二。

## 延期与后续

资源点暂时持续供给，不枯竭、不再生；没有伐树动画、矿量、矿石种类、工具链、运输、资源点共享效率或新地图生成。建筑不能取消、退款或拆除，需注意不要用其他建筑堵住采集入口。

下一步可在生产、仓储和材料基础上接入建筑信息与生产管理，随后逐步加入加工链和居民满意度；军队系统放在经济闭环稳定之后开发。

实际窗口补充检查：已确认森林/石矿色块及文字标记可见，右侧滚动后可操作两种新建造按钮；普通内陆确认伐木场显示红色占地并提示须紧邻森林，合法临林位置成功生成0%工地且仅扣10金币。该临时测试未保存玩家进度。
