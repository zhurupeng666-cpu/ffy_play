# 建筑占地预览与合法性验收

## 当前范围

新增住宅2×2、农场4×4两种多格占地预览，仅判断几何尺寸、地图边界和占用重叠。没有实际建造、材料扣费、施工队列、人口容量、农场生产或建筑存档。绿色仅代表位置合法，不代表资源、道路或地形等完整建造条件均已满足。

地图中央逻辑坐标x=6至9、y=6至9为蓝灰色测试占用区，不是真实领主厅或玩家建筑，不会生产、消费或写入战略存档。后续实际建造接入时应替换为世界建筑数据推导出的占用表，不能把该测试区当正式初始城镇。

## 静态数据与模块

building_definition.gd定义Resource配置字段id、display_name、footprint和cost。house.tres与farm.tres分别定义住宅与农场，费用暂按原设计为木20金10、木25金10，均待平衡；此阶段费用未参与判定或扣除。

Resource文件是引擎配置而非业务代码，文件用途在本记录说明，保持合法格式。手写GDScript均有中文用途说明与模块注释。

placement_validator.gd是纯数据校验器，返回ok、稳定错误码、原因与完整占地格列表。先拒绝异常尺寸，再检查全部格的地图边界，最后检查占用。与已有地块仅贴边不算重叠，部分格重叠也会拒绝。该函数不修改占用字典或库存。

town_map.gd负责预览颜色、坐标变换、输入与取消；world_prototype.gd只选择定义并显示原因，不创建建筑或执行SQL。日结、资源和战略快照数据结构未变。

## 交互约定

- 选择住宅或农场后进入预览，鼠标所在逻辑格为锚点，沿逻辑x和y正方向扩展整个矩形。
- 空闲且完整位于地图内时全部格显示绿色；任一格越界或重叠时全部格显示红色，并在管理面板提供文字原因。
- 鼠标离开地图后隐藏占地，提示请移入地图，不把无效坐标当成可建位置。
- 预览模式左键仅检查位置并提示；重复点击也不建造、不新增占用、不扣费。
- 右键、取消按钮或第一次Esc退出预览，恢复普通选格；无预览时Esc才退出程序。
- 拖动、缩放、Home复位继续可用，校验始终使用逻辑格而非屏幕像素。
- 预览类型与鼠标位置不保存，已有战略存档可继续使用。

- 负坐标、整块越界、零尺寸、异常大尺寸被拒绝。
- 部分重叠拒绝，贴边不重叠通过，校验不改占用表。

- 合法位置重复左键不增加占用；右键与Esc均取消模式。
- 场景级快照检查确认合法和非法点击后世界资源、人口、日期不变。
