# 建筑详情与岗位直达验收

## 本步行为

玩家在普通模式点击地图建筑的任一占地格，按当前世界查询稳定建筑ID，显示管理面板中的详情卡并高亮完整占地。右侧自动滚动到详情卡，原有时钟、存档、建造和生产列表保留。

详情包含名称、等级、实例编号、坐标、尺寸和状态。工地显示完成百分比、已做/所需工作、施工队列位置、施工工人数、等待或停工原因及世界暂停提示。完工生产建筑显示岗位、全镇空闲、当前全天折算产量、待日结的实际累计产量和暂停/无人工作状态。

完工住宅显示本座+10住房，粮仓显示本座静态配置容量（当前300），领主厅显示初始住房/公共储粮职责。这些值不与全镇总容量混淆。所有既有数值仍为待平衡参数，本步不改平衡。

详情内“本建筑工人 -1/+1”与现有生产下拉框互相同步目标。零人禁止减员，满员/无空闲禁止加人，未完工的生产建筑禁用岗位按钮，非生产建筑隐藏岗位按钮。世界层仍再次校验每一次请求，禁用按钮并非唯一保护。

## 状态与边界

- 点击空地、资源点、地图外逻辑格或普通模式右键清空详情与建筑高亮；资源点暂不提供独立详情。
- 进入建造模式清空旧选择；成功后自动查看新工地。建造模式右键仍只取消预览。
- 切换生产下拉框会取消尚未确认的建造预览，再选中对应建筑。
- 完工、进度、暂停和岗位变化会刷新详情，不保存第二份生产数值。
- 读档成功时清空地图选择；重新点击时从当前世界重新解析ID。读档失败保持原世界与选择。
- 选择与高亮是纯界面状态，不写入战略存档；快照仍v7、SQLite结构仍v2，不迁移任何玩家数值。
- 没有升级、拆除、退款、工地取消、多选或每栋独立停产开关。生产岗位为0即可停产，原有累计工作保留。

## 模块

building_inspector.gd提供只读find/at_cell/describe：按稳定ID查询、完整矩形占地命中、详情文本及可用操作。每次从当前权威世界取记录，不保留跨读档的字典引用。

world_prototype.gd协调地图选择、生产下拉框、详情卡、自动滚动和岗位命令；岗位最终仍交给world.assign_producers处理。town_map.gd只保存界面高亮ID并绘制占地轮廓，不执行岗位或库存逻辑。

原生产列表与地图选中使用同一目标，但未选中建筑时列表仍可作为独立入口；玩家真正切换选项后才建立详情选择。选中非生产建筑不会改变另一个生产建筑的工人数。

## 验证

inspection_test通过真实管理场景和地图输入验证：领主厅非锚点选择、4×4占地全部命中、边界外不误选、只读不改世界、排队工地、暂停/零施工工人、百分比和完工切换、详情按钮信号、下拉联动、满员/无人可用限制、住宅/粮仓容量、材料单位和待入库量、存档岗位恢复与旧选择清空、建造模式及新工地自动选择、右键与资源点清空。

完整构建13项测试，debug/release共28项独立进程检查。新增inspect写进程通过界面建伐木场、选择岗位并保存第135秒待入库1木材；新读进程读取后从建筑内部格重新点选，加到2人，再推进到第240秒，验证木材135和岗位目标正确。测试数据与玩家存档隔离。

构建日志位于E:/playproject/builds/inspection-build.log，未提交exe、数据库和引擎缓存。手动测试见开发测试指南步骤十三；自动输入检查不替代全部人工布局与交互验收。

## 后续

建筑详情作为后续加工配方、建筑等级和维护信息的入口，先稳定直接管理体验，再逐步扩展加工链或居民需求，不在本步加入新经济变量。

实际窗口补充检查：已确认领主厅任意内部格点击后全占地出现黄色线条，详情名称、位置、尺寸与完工信息正常，且不出现生产按钮。旧生产列表按钮也会在修改前同步其目标到详情和地图，避免刚查看非生产建筑时出现误解；该行为已加入自动测试。临时画面检查未保存玩家进度。
