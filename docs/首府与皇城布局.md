# 首府与皇城布局

外城为 300×300 格，格网范围从 `(-15,-230)` 到 `(284,69)`。主城区向北扩张，河流和河港处于城外。四面各设一座大型门楼，主干路通向城门，东南部保留普通城镇与既有产业。皇城在外城内另设围墙、四门、四角楼与独立院落。历史参考来自北京市文物局的皇城功能分区及故宫博物院的外朝、内廷布局。

- 外朝有太和殿、中和殿、保和殿、文华殿和武英殿。
- 内廷有乾清宫、交泰殿、坤宁宫、东六宫、西六宫、慈宁宫和宁寿宫。
- 礼仪和苑囿有太庙、社稷坛和御花园。
- 行政、内务和卫戍有内阁衙署、内务府、内府库坊、御膳房、禁卫值房、钟鼓值楼。
- 皇城设施可整栋点选，右侧显示名称、用途和占地。官员与富商府邸采用 15×15 格，院内设正厅、厢房、通路、园池、石桥与后屋。
- 平常道路上的居民沿实际接通的路段走，公用大道和皇城前庭另设步行路线。脚夫、拎篮住户、长衫行人、孩童和巡街护卫有不同剪影及步态，行人走不同路侧，在终点停步再折返。皇城模块属于世界布局，保存布局标志即可重建。

普通城区新增的宽街每段占 3×3 格，连铺时共享路缘。新住宅入口必须接到完工街道；有多条街时优先朝接壤最多的一侧。门向随存档保存，旧房按实际临街方向显示。居民开店和营建府邸时也从路边找空地。

「皇宫布置」可切换殿内剖视，或在西苑、东苑、礼仪花庭和西书房放置陈设、换地砖。布置随战略存档保存。首府城墙内没有林矿资源点，旧档中的采集场迁往城外同类资源旁。

历史参考：[北京市文物局·北京皇城保护规划](https://wwj.beijing.gov.cn/bjww/362679/362686/622504/index.html) · [故宫博物院·建筑](https://www.dpm.org.cn/explore/buildings/p/6.html)。
