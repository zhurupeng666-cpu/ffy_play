# 等距城镇格网与镜头验收

## 范围

本阶段为16×16城镇占位格网，逻辑格尺寸64×32像素。左侧地图、右侧战略管理均为功能占位布局，不是正式界面或地形美术。格网尚无建筑、道路、地形阻挡和生产能力。

## 坐标与模块

isometric_grid.gd负责投影与反选：世界x=(格x-格y)×32，世界y=(格x+格y)×16。格子坐标从0开始，合法范围0至15。反选采用同一坐标系，菱形边界归属固定，不用贴图像素猜测地块。

town_map.gd是独立Control，绘制格网并维护镜头变换；缩放与平移只作用于地图，不影响管理界面。世界到屏幕的变换为控件中心+平移+(世界位置-地图中心)×缩放。鼠标反选先执行逆变换，再调用逻辑坐标转换。

当前以控件内变换实现2D镜头，不引入实体角色或物理移动。未来可替换为Camera2D，但投影和格子ID不应随之变化。

## 交互

- 悬停：黄色边线与坐标提示；移出地图后清除悬停。
- 左键：选择地块，显示绿色标记与选中坐标；点击地图外空白清除选择。
- 右键：取消选择。
- 中键按住拖动：移动地图；地图外释放或窗口失焦后停止拖动。
- 滚轮：以鼠标所指世界位置为锚点缩放，范围50%至200%。
- Home或镜头复位按钮：回到地图中心和75%缩放，保留已选地块。

地图采用裁剪，放大或默认视图下边缘地块可能不在窗口内，可拖动或缩小查看。当前允许自由拖出视区，复位可找回地图；镜头边界限制延期。地图外的管理按钮不把点击或滚轮传给地图，侧栏内容过长时可滚动。

## 数据边界

地图交互不改变人口、库存、日期和日结。镜头、悬停和选格都是临时界面状态，不保存；重开后恢复默认视图。战略数据库结构与路径不变，已有战略档可继续读取。选格不等于建造，也不会扣材料。
